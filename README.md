
# Search Engine

A search engine designed for efficient retrieval and discovery.

## Requirements

- Python 3
- BeautifulSoup4
- lxml
- NLTK

Install the required libraries:

```bash
python -m pip install beautifulsoup4 lxml nltk
```

## Dataset

Download the provided dataset `DEV` folder in the project directory.

## Building the Inverted Index

Run the indexer:

```bash
python disk_indexer.py
```

## Index Statistics

To display the index statistics, run:

```bash
python index_stats.py
```
